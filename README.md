# 🚀 Featured Project

<div align="center">

## 🤖 Anime Sticker Bot

### A Telegram bot for managing anime sticker packs

</div>

One of my main projects is a Telegram bot focused on **anime sticker
packs and their moderation**.

The project grew into a fairly complete backend system with users,
sticker packs, applications, ratings, moderation and persistent storage.

### ✨ Features

* 🎴 Add and manage sticker packs
* 🗂️ Categories and sticker pack management
* ⭐ Like / dislike rating system
* 🛡️ Moderation
* 📨 Sticker applications
* 👤 User management
* 🗄️ PostgreSQL persistence
* 💾 JSON serialization
* 🔐 Separation of application logic and infrastructure
* ⚡ Modern C++20 codebase
